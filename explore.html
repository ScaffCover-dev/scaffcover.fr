Configuration details

Start with the project need, then optimise the scaffold design with ScaffCover. Select the connector or coupler for the actual scaffold type — for example Ringlock, Kwikstage or tube-and-fitting. Establish track height, length and layout; match suspension bars to the bay widths; select the required joiner and plastic components from the Connects range. Coordinate the panel layout and, for weather protection, drainage so water can run off. The exact engineering remains project-specific.

Your project

What is ScaffCover?

A complete modular containment system for scaffold cladding and roofing.

Why use it?

Configure the containment for the job, using the appropriate connections with the customer’s scaffold. Select the Guard panel for the work being done.

What’s different?

The components work together through deployment, containment, recovery and reuse. Cost-competitive supply and reduced maintenance contribute to the overall value.

Is it ready for the European market?

ScaffCover is preparing for the European market. Work on the applicable European requirements, testing and technical documentation is underway, with the required information intended to be available at launch.

For a specific standard or test result, the technical team can confirm the current status and applicable evidence. Completed European certification is not being claimed at this stage.
